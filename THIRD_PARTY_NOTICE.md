# Third-party and upstream review notice

SmartDoc was developed from a repository that was originally forked. Before any
commercial distribution, the project owner must identify the upstream URL and
license, retain every required copyright/license notice, and verify that the
chosen commercial distribution model is compatible with that license.

The `LICENSE` file in this repository applies only to original SmartDoc work. It
does not relicense third-party source code, dependencies, fonts, icons, templates,
or media assets.

## Required manual review before commercial release

1. Record the original upstream repository URL and commit in this file.
2. Copy the upstream license and notices into `licenses/upstream/`.
3. Run a dependency license and vulnerability report in CI.
4. Review static PPT templates, images, fonts, icons, OCR language data and sample
   documents for redistribution rights.
5. Obtain legal advice if the upstream license or asset provenance is unclear.
